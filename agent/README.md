# pc-agent — агент родительского контроля (Python)

Новая версия агента на Python. Она постепенно заменит скрипты PowerShell в корне репозитория.
**Не запускайте обе версии одновременно**: каждая будет считать время и завершать сеанс сама по себе.

## Что умеет сейчас

- Учитывает время, только когда сеанс ребёнка на экране и не заблокирован.
  Время между проверками считается по монотонным часам, поэтому перевод часов на ПК
  не добавляет и не убирает минуты. Сон или гибернация тоже не засчитываются.
- Задаёт дневной лимит (отдельно для будней и выходных) и разрешённые часы,
  принимает бонусное время и блокировку до конца дня.
- Показывает предупреждения (по умолчанию за 10, 5 и 1 мин). Когда время вышло,
  через минуту сеанс завершается (`logoff`) или возвращается на экран входа (`lock`).
- Закрывает запрещённые программы, имена можно задавать с `*`. Программа узнаётся и после
  переименования файла: агент сверяет и сведения внутри exe (исходное имя файла, название продукта, описание).
- В журнал попадает запуск и закрытие программ, а не каждого процесса (у Chrome их десятки).
  Программы, открытые до запуска агента, не записываются.
- Записывает смену часового пояса (`timezone_changed`), в том числе сделанную до перезагрузки.
- Хранит журнал 90 дней, а счётчики времени около года.
- Ведёт журнал в SQLite: запуск и завершение программ, предупреждения,
  завершения сеанса, ошибки.
- Сообщения ребёнку показывает прямо из службы (`WTSSendMessage`),
  отдельная задача от имени ребёнка не нужна.
- **Helper в сеансе ребёнка.** Служба сама запускает `pcagent.exe helper` от имени ребёнка.
  Каждые 2 секунды helper передаёт службе через именованный канал, какое окно в фокусе
  и сколько времени нет ввода с мыши и клавиатуры. В трее он показывает значок с остатком времени:
  зелёный, жёлтый или красный. Пунктов меню «Выход» у значка нет.
  - Если ребёнок ничего не нажимает дольше `idle_minutes` (по умолчанию 3 мин), время не считается.
  - Время засчитывается каждой программе отдельно (`pcagent status`, раздел «Программы сегодня»).
    В журнал пишется каждое окно с заголовком и длительностью (`window_focus`).
    У браузера в заголовке видно название страницы или видео.
  - Если helper завершат, служба через 10 секунд запустит его снова и запишет событие `helper_stopped`.
  - Данные принимаются только от процесса, который запустила служба. Подделку,
    которая пытается выдать ребёнка за отсутствующего, служба отклонит.
  - Если helper недоступен, время считается без учёта бездействия, то есть в пользу родителя.

## Разработка

```bash
uv sync
uv run pytest
uv run ruff check .
```

Пробный запуск без последствий: агент ничего не закрывает и не завершает сеанс, данные хранятся в отдельной папке.

```bash
uv run pcagent --data-dir .\devdata init --child ИмяРебёнка
uv run pcagent --data-dir .\devdata run --dry-run
uv run pcagent --data-dir .\devdata status
uv run pcagent --data-dir .\devdata events -n 30
```

## Сборка и установка службы

Сборка создаёт папку `dist\pcagent\` с `pcagent.exe`. Python на компьютере ребёнка не нужен.

```bash
powershell -ExecutionPolicy Bypass -File scripts\build-agent.ps1
```

Установка (в терминале, запущенном от имени администратора):

```bash
dist\pcagent\pcagent.exe service install
```

Что делает `service install`:
- копирует программу в `C:\Program Files\ParentalControl\agent\`, куда ребёнок не может ничего записать;
- закрывает папку данных `C:\ProgramData\ParentalControl\agent\` от записи для обычных пользователей;
- регистрирует службу `ParentalControlAgent`: запуск от имени SYSTEM, автоматический старт
  с Windows и перезапуск через 5 секунд, если процесс упал или его завершили;
- разрешает службе запускаться и в безопасном режиме, иначе там не было бы контроля;
- запрещает обычным пользователям менять часовой пояс. Сменой пояса можно досрочно начать
  «завтра» и обнулить использованное время. Запрет действует со следующего входа ребёнка;
- запускает службу.

Если на компьютере работает старая версия на PowerShell, установка остановится.
Две версии одновременно независимо считали бы время и завершали сеанс.
Удалите старую версию (`parent.cmd` → U) или добавьте `--disable-old`, чтобы её задача была отключена.

Повторный `service install` из новой сборки обновляет уже установленную службу.
Остальные команды управления: `service status | start | stop | restart | remove`.
`service remove` возвращает часовой пояс и безопасный режим к настройкам Windows по умолчанию.

После установки создайте правила, тоже от имени администратора:

```bash
"C:\Program Files\ParentalControl\agent\pcagent.exe" init --child ИмяРебёнка
```

`init` проверяет, что такая учётная запись есть и что она **не** администратор.
Если ребёнок администратор, он может отключить что угодно.

Проверка службы целиком: установка, перезапуск после завершения процесса, обновление и удаление.
Скрипт после себя всё удаляет.

```bash
powershell -ExecutionPolicy Bypass -File scripts\test-service.ps1
```

## Пароль родителя

У агента есть собственный пароль, не связанный с учётными записями Windows.
С ним можно управлять агентом прямо из учётной записи ребёнка, не выходя из неё.

```bash
"C:\Program Files\ParentalControl\agent\pcagent.exe" set-password
```

Команду нужно запускать от имени администратора. После этого:
- **Окно родителя.** Щелчок по значку в трее ребёнка (или пункт меню «Родитель...») открывает окно.
  В нём вводится пароль, после чего доступны «+15 мин», «+30 мин», «+1 час»,
  «Заблокировать до конца дня» и «Снять блокировку». Пароль вводится один раз за открытие окна.
- **Консоль.** `pcagent bonus 30`, `block` и `unblock`, запущенные без прав администратора,
  спросят пароль и выполнятся через службу.

Как пароль защищён:
- **Хранение.** Хранится только хеш scrypt с солью, в файле `parent.key`. Прочитать этот файл
  могут только SYSTEM и администраторы, поэтому ребёнок не может скопировать хеш и подбирать пароль у себя.
- **Проверку делает служба.** После 5 неверных попыток ввод блокируется на 5 минут.
  Каждая неверная попытка записывается в журнал (`wrong_password`).
- **Пароль уходит только службе.** Окно отправляет пароль, только если канал создан процессом
  в нулевом сеансе, то есть службой. Если служба остановлена и ребёнок создал канал с тем же
  именем, чтобы перехватить пароль, окно ничего не отправит.

Чего пароль не защищает: администратор Windows всё равно может остановить или удалить службу.

## Подключение к серверу родителя

Агент работает и без сервера. Сервер (папка `server/`) добавляет веб-панель: в ней можно
смотреть, что делает ребёнок, и управлять с телефона или другого компьютера.

```bash
"C:\Program Files\ParentalControl\agent\pcagent.exe" connect --server http://адрес:8000 --code КОД --name "Компьютер Маши"
```

Код выдаёт веб-панель (кнопка «Добавить компьютер»). Адрес сервера и токен устройства
хранятся в `server.json`, прочитать его могут только SYSTEM и администраторы. Что делает служба:
- **Отправка на сервер.** Каждые 15 секунд отправляет статус: сколько осталось и что открыто.
  Вместе с ним уходят новые записи журнала и время по программам.
- **Правила.** Получает новые правила из панели и записывает их в `rules.json`.
- **Команды.** Выполняет команды родителя («+30 мин», «заблокировать»). Каждая выполняется
  ровно один раз, даже если сервер прислал её повторно.

Если сервер недоступен, контроль продолжает работать, а данные отправятся позже.
Отключить компьютер от сервера: `pcagent disconnect`.

## Команды

| Команда | Что делает |
|---|---|
| `pcagent init --child NAME` | создаёт `rules.json` |
| `pcagent check-rules` | проверяет `rules.json` |
| `pcagent run [--dry-run]` | запускает агент в консоли |
| `pcagent status` | показывает использованное и оставшееся время, историю |
| `pcagent set-password` | задаёт пароль родителя (от имени администратора) |
| `pcagent parent` | открывает окно родителя |
| `pcagent connect --server URL --code КОД` / `disconnect` | подключает к серверу родителя или отключает от него |
| `pcagent bonus 30` / `bonus -15` | меняет время на сегодня (без прав администратора спросит пароль) |
| `pcagent block` / `unblock` | блокирует до конца дня или снимает блокировку |
| `pcagent events -n 50` | выводит журнал |
| `pcagent service install/status/start/stop/restart/remove` | управляет службой Windows (только из собранного exe) |

По умолчанию данные хранятся в `C:\ProgramData\ParentalControl\agent\`: `rules.json`, `agent.db`, `agent.log`.
Другую папку можно задать через `--data-dir` или переменную окружения `PC_AGENT_DATA`.

## Пример rules.json

```json
{
  "child_user": "Kid",
  "weekdays": { "limit_minutes": 120, "window": { "start": "08:00", "end": "21:00" } },
  "weekends": { "limit_minutes": 180, "window": { "start": "09:00", "end": "22:00" } },
  "warn_at_minutes": [10, 5, 1],
  "idle_minutes": 3,
  "enforcement": "logoff",
  "blocked_apps": ["RobloxPlayerBeta", "Minecraft*"],
  "blocked_sites": []
}
```

Если в изменённом `rules.json` ошибка, агент продолжит работать по прежним правилам
и запишет в журнал событие `rules_error`.

## Пока не сделано

- Подпись exe цифровым сертификатом. Без неё SmartScreen или антивирус могут предупреждать о `pcagent.exe`.
- Блокировка сайтов (`blocked_sites` пока не применяется), расширение браузера.
- Синхронизация с сервером.
