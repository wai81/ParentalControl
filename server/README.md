# pc-server — сервер родительского контроля

Веб-панель для родителя и API для агентов на компьютерах детей.
Технологии: FastAPI и SQLite, страницы рендерятся на сервере и работают на телефоне.

## Что умеет

- **Компьютеры.** Список компьютеров: в сети или нет, сколько осталось времени, что сейчас открыто.
- **Подключение агента** по одноразовому коду из панели. Код действует 15 минут.
- **Управление:** «+15 / +30 / +60 / −15 мин», «Заблокировать до конца дня», «Снять блокировку».
  Команда выполняется в течение нескольких секунд. Если компьютер выключен, она выполнится,
  когда он подключится.
- **Правила.** Лимиты для будней и выходных, разрешённые часы, предупреждения, бездействие,
  запрещённые программы. Агент получает их сам.
- **Статистика и журнал.** Время по программам и по дням. В журнале видны окна, запуски,
  предупреждения, команды и попытки обхода; события, требующие внимания, подсвечены.

Если сервер недоступен, агенты продолжают работать по последним правилам.
Накопленные данные они отправят, когда связь восстановится.

## Установка на Raspberry Pi

Подойдёт Raspberry Pi 3, 4 или 5 с **64-битной** Raspberry Pi OS (Lite достаточно)
либо любой Debian или Ubuntu с systemd. Серверу хватает нескольких десятков мегабайт памяти.

**1. Соберите архив** (на компьютере с исходниками):

```bash
uv run python scripts/package-server.py
```

Появится `dist\pc-server-0.1.0.tar.gz`.

**2. Скопируйте его на Pi.** Вместо `pi@raspberrypi.local` подставьте своего пользователя и адрес Pi:

```bash
scp dist\pc-server-0.1.0.tar.gz pi@raspberrypi.local:
```

**3. Установите на Pi:**

```bash
tar xzf pc-server-0.1.0.tar.gz && cd pc-server-0.1.0 && sudo ./server/deploy/install.sh
```

Установщик выполнит следующее:
- поставит uv, а через него Python 3.13. Системный Python не трогается;
- создаст системного пользователя `pcserver` без входа в систему;
- установит программу в `/opt/pc-server`, а данные будет хранить в `/var/lib/pc-server`;
- создаст настройки в `/etc/pc-server.env`;
- зарегистрирует службы:
  - `pc-server` запускается при включении Pi и перезапускается при сбое.
    Изолирована средствами systemd: писать может только в свою папку данных;
  - `pc-server-backup.timer` раз в сутки копирует базу в `/var/lib/pc-server/backups`
    и хранит 14 последних копий;
- при первой установке спросит пароль родителя для веб-панели;
- в конце покажет адрес панели в домашней сети.

Установщик проверен:
- **на Raspberry Pi 4B** с Raspberry Pi OS Lite 64-bit (arm64): установка прошла без ошибок;
- **в Ubuntu 26.04** (x86_64, systemd): чистая установка, повторный запуск как обновление,
  удаление. Оценка изоляции службы по `systemd-analyze security`: 1.3 (OK).

**Обновление:** соберите новый архив, скопируйте на Pi и снова запустите `install.sh`.
База, пароль, ключ сессий и настройки сохраняются.

**Полезные команды на Pi:**

| Что | Команда |
|---|---|
| Состояние сервера | `systemctl status pc-server` |
| Журнал сервера | `journalctl -u pc-server -f` |
| Перезапуск после правки `/etc/pc-server.env` | `sudo systemctl restart pc-server` |
| Резервная копия вручную | `sudo systemctl start pc-server-backup` |
| Сменить пароль панели | `sudo runuser -u pcserver -- env PC_SERVER_DATA_DIR=/var/lib/pc-server /opt/pc-server/venv/bin/pc_server set-password` |
| Удалить сервер (данные останутся) | `sudo ./server/deploy/uninstall.sh` |
| Удалить вместе с данными | `sudo ./server/deploy/uninstall.sh --purge` |

### Доступ: дома и вне дома

- **Компьютеры детей дома** подключаются к Pi по домашней сети: `http://192.168.x.x:8000`.
  Этот адрес показывает установщик. Pi лучше закрепить постоянный адрес в настройках роутера
  (резервирование DHCP), иначе после перезагрузки роутера адрес может смениться.
- **Телефон родителя вне дома:** через [Tailscale](https://tailscale.com), бесплатно для личного
  использования. Порты на роутере открывать не нужно, Pi не виден из интернета.
  1. На Pi:
     ```bash
     curl -fsSL https://tailscale.com/install.sh | sh
     ```
     Затем:
     ```bash
     sudo tailscale up
     ```
     Откройте показанную ссылку и войдите.
  2. Включите https для панели:
     ```bash
     sudo tailscale serve --bg 8000
     ```
     Панель станет доступна по адресу `https://<имя-pi>.<ваша-сеть>.ts.net`.
  3. Поставьте приложение Tailscale на телефон и войдите в ту же учётную запись.
  4. Если панель открывается только по https, в `/etc/pc-server.env` поставьте
     `PC_SERVER_SECURE_COOKIES=true` и перезапустите сервер.
- **Ноутбук ребёнка вне дома** не достанет до Pi по домашнему адресу. Контроль на нём продолжит
  работать по последним правилам, а данные он отправит, когда вернётся домой.
  Если нужна связь и вне дома, поставьте Tailscale и на ноутбук,
  а в `pcagent connect` укажите адрес из Tailscale.

Через Tailscale Serve к серверу обращается локальный прокси. Сервер доверяет заголовкам
`X-Forwarded-*` только от `127.0.0.1`, поэтому другие клиенты не могут подделать свой адрес.

## Запуск без установки (разработка, Windows)

```bash
uv sync
uv run pc_server set-password
uv run pc_server serve --port 8000
```

Панель откроется по адресу `http://адрес-сервера:8000`.
Данные лежат в `./data`: база `server.db` и ключ сессий `secret.key`.

Настройки задаются переменными окружения:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PC_SERVER_DATA_DIR` | `./data` | папка с базой и ключом |
| `PC_SERVER_DATABASE_URL` | SQLite в папке данных | другая база |
| `PC_SERVER_SECURE_COOKIES` | `false` | `true`, если панель открывается по https |
| `PC_SERVER_PAIRING_CODE_MINUTES` | `15` | сколько действует код подключения |

## Подключение компьютера

1. В панели нажмите «Добавить компьютер». Появится код и готовая команда.
2. На компьютере ребёнка, где уже установлен агент, выполните эту команду в PowerShell от имени администратора:
   ```bash
   & "C:\Program Files\ParentalControl\agent\pcagent.exe" connect --server http://адрес-сервера:8000 --code 12345678 --name "Компьютер Маши"
   ```
3. Через несколько секунд компьютер появится в панели. Его текущие правила станут правилами на сервере.
   Дальше правила меняются в панели.

Отключить компьютер: `pcagent disconnect` на нём самом или «Удалить устройство» в панели.

## Безопасность

- **Шифрование.** Агент передаёт токен устройства и данные о ребёнке. Через интернет нужен **https**.
  Варианты:
  - **Tailscale** или WireGuard: сервер и компьютеры в одной частной сети, порты наружу не открываются.
    Это самый простой вариант для домашнего сервера.
  - **Caddy** перед сервером: сам получает сертификат Let's Encrypt.
    Достаточно `reverse_proxy localhost:8000` и `PC_SERVER_SECURE_COOKIES=true`.
- **Пароль родителя.** Хранится как хеш scrypt. После 5 неверных паролей вход блокируется на 5 минут.
- **Токены устройств.** Хранятся как SHA-256. Удалённое устройство больше не может подключиться.
- **Формы панели** защищены от CSRF, cookie сессии с `SameSite=Strict`.
