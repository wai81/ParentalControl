# pc-server — сервер родительского контроля

Веб-панель для родителя и API для агентов на компьютерах детей.
Технологии: FastAPI и SQLite, страницы рендерятся на сервере и работают на телефоне.

## Что умеет

- **Компьютеры.** Список компьютеров: в сети или нет, сколько осталось времени, что сейчас открыто.
- **Подключение агента** по одноразовому коду из панели. Код действует 15 минут.
- **Управление:** «+15 / +30 / +60 / −15 мин», «Заблокировать до конца дня», «Снять блокировку».
  Команда выполняется в течение нескольких секунд. Если компьютер выключен, она выполнится,
  когда он подключится.
- **Правила.** Лимиты для будней и выходных, разрешённые часы, предупреждения, бездействие,
  запрещённые программы. Агент получает их сам.
- **Статистика и журнал.** Время по программам и по дням. В журнале видны окна, запуски,
  предупреждения, команды и попытки обхода; события, требующие внимания, подсвечены.

Если сервер недоступен, агенты продолжают работать по последним правилам.
Накопленные данные они отправят, когда связь восстановится.

## Запуск

```bash
uv sync
uv run pc_server set-password
uv run pc_server serve --port 8000
```

Панель откроется по адресу `http://адрес-сервера:8000`.
Данные лежат в `./data`: база `server.db` и ключ сессий `secret.key`.

Настройки задаются переменными окружения:

| Переменная | По умолчанию | Что это |
|---|---|---|
| `PC_SERVER_DATA_DIR` | `./data` | папка с базой и ключом |
| `PC_SERVER_DATABASE_URL` | SQLite в папке данных | другая база |
| `PC_SERVER_SECURE_COOKIES` | `false` | `true`, если панель открывается по https |
| `PC_SERVER_PAIRING_CODE_MINUTES` | `15` | сколько действует код подключения |

## Подключение компьютера

1. В панели нажмите «Добавить компьютер». Появится код и готовая команда.
2. На компьютере ребёнка, где уже установлен агент, выполните эту команду в PowerShell от имени администратора:
   ```bash
   & "C:\Program Files\ParentalControl\agent\pcagent.exe" connect --server http://адрес-сервера:8000 --code 12345678 --name "Компьютер Маши"
   ```
3. Через несколько секунд компьютер появится в панели. Его текущие правила станут правилами на сервере.
   Дальше правила меняются в панели.

Отключить компьютер: `pcagent disconnect` на нём самом или «Удалить устройство» в панели.

## Безопасность

- **Шифрование.** Агент передаёт токен устройства и данные о ребёнке. Через интернет нужен **https**.
  Варианты:
  - **Tailscale** или WireGuard: сервер и компьютеры в одной частной сети, порты наружу не открываются.
    Это самый простой вариант для домашнего сервера.
  - **Caddy** перед сервером: сам получает сертификат Let's Encrypt.
    Достаточно `reverse_proxy localhost:8000` и `PC_SERVER_SECURE_COOKIES=true`.
- **Пароль родителя.** Хранится как хеш scrypt. После 5 неверных паролей вход блокируется на 5 минут.
- **Токены устройств.** Хранятся как SHA-256. Удалённое устройство больше не может подключиться.
- **Формы панели** защищены от CSRF, cookie сессии с `SameSite=Strict`.
